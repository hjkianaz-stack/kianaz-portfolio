# Kianaz Portfolio

Modern portfolio landing page for **Content Strategist & AI Automation Specialist**.

## Stack
- React
- Vite
- Lucide React
- CSS
- Deployable on Cloudflare Pages or Render

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cloudflare Pages
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`

## First things to customize
1. Replace `hello@example.com` in `src/main.jsx`.
2. Replace project `href` values with your real project URLs.
3. Replace GitHub / LinkedIn `href` values.
4. Add screenshots to the project cards if desired.
